# COROP regions in the Netherlands

An `sf` object with COROP region geometries for the Netherlands.
Centroid coordinates are included in EPSG:4326.

## Usage

``` r
nl_corop
```

## Format

A simple feature object with 40 rows and 5 variables:

- corop_nr:

  COROP number.

- areaname:

  COROP region name.

- geometry:

  COROP region geometry.

- lon:

  Longitude of the COROP centroid.

- lat:

  Latitude of the COROP centroid.

## Source

Statistics Netherlands (CBS), adapted for package examples.

## Details

COROP regions are regional areas used for analytical purposes by, among
others, Statistics Netherlands.
