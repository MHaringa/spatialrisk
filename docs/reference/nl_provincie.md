# Provinces in the Netherlands

An `sf` object with province geometries for the Netherlands. Centroid
coordinates are included in EPSG:4326.

## Usage

``` r
nl_provincie
```

## Format

A simple feature object with 12 rows and 4 variables:

- areaname:

  Province name.

- geometry:

  Province geometry.

- lon:

  Longitude of the province centroid.

- lat:

  Latitude of the province centroid.

## Source

Statistics Netherlands (CBS), adapted for package examples.
